# Gerador de Políticas de Privacidade

## Propósito
Redigir políticas de privacidade abrangentes e conformes para produtos e serviços digitais. A política cobre tipos de dados tratados, jurisdição aplicável e marca claramente as cláusulas que exigem revisão legal, fornecendo explicações acessíveis para transparência com os usuários.

## Como Funciona
A skill gera uma política de privacidade completa estruturada em seções padrão: informações coletadas, métodos de coleta, usos dos dados, base legal para processamento, compartilhamento com terceiros, transferência internacional, retenção de dados, direitos dos usuários, cookies e rastreamento, segurança, privacidade infantil e informações de contato.

## Quando Usar
- Lançamento de novos produtos ou serviços digitais
- Atualização de práticas de coleta de dados
- Expansão para novas jurisdições (internacionalização)
- Conformidade com regulamentações (GDPR, LGPD, CCPA)
- Antes de campanhas de marketing ou coleta massiva de dados
- Quando implementar novas tecnologias de rastreamento

## Passo a Passo

### 1. Mapeamento de Coleta de Dados
Identifique todos os dados que seu produto coleta:

**Coleta Direta**
- Informações de cadastro (nome, email, telefone)
- Dados de perfil (preferências, interesses)
- Informações de pagamento (cartões, endereços de cobrança)
- Comunicações (mensagens de suporte, feedback)

**Coleta Automática**
- Endereço IP e geolocalização
- Informações do dispositivo (tipo, SO, browser)
- Comportamento de uso (páginas visitadas, tempo)
- Cookies e identificadores únicos
- Dados de analytics e performance

**Dados de Terceiros**
- Informações de parceiros e integrations
- Dados de redes sociais (com autorização)
- Informações de verificação de identidade

### 2. Identificação de Leis Aplicáveis
Determine quais regulamentações se aplicam:

**LGPD (Brasil)**
- Usuários brasileiros: obrigatório
- Requer consentimento explícito
- Direitos de acesso, correção, exclusão
- ANPD como autoridade fiscalizadora

**GDPR (União Europeia)**
- Usuários da UE: obrigatório
- Base legal para cada tipo de processamento
- Direitos extensivos dos titulares
- Requer DPA com processadores

**CCPA/CPRA (Califórnia)**
- Residentes da Califórnia: obrigatório
- Direitos de saber, deletar, opt-out
- Não discriminação por exercer direitos
- Divulgações detalhadas obrigatórias

### 3. Estruturação da Política
Organize a política nas seguintes seções:

**Preâmbulo**
- Qual política cobre
- Data da última atualização
- Como entrar em contato

**Informações Coletadas**
- Listagem detalhada por categoria
- Explicação do porquê de cada coleta
- Dados sensíveis (se aplicável)

**Como Usamos as Informações**
- Propósitos específicos (não vagos)
- Base legal para cada uso
- Melhorias e personalização

**Compartilhamento e Terceiros**
- Service providers (hosting, analytics, email)
- Parceiros de negócio (se aplicável)
- Autoridades legais (se requerido)

**Direitos dos Usuários**
- Como exercer direitos específicos
- Prazos de resposta
- Processos de verificação

### 4. Personalização por Jurisdição
Adapte o conteúdo para as leis específicas:

**Para LGPD**
- Incluir base legal específica (consentimento, contrato, etc.)
- Detalhar direitos dos titulares
- Informar sobre ANPD

**Para GDPR**
- Explicar base legal para cada processamento
- Incluir informações sobre DPIA se necessário
- Detalhar direitos de portabilidade

## Exemplo Prático

**Situação:** SaaS brasileiro de gestão de projetos com clientes internacionais

**Configuração:**
- Produto: ProjectFlow Brasil
- Dados: Nome, email, comportamento na plataforma, dados de pagamento
- Jurisdições: Brasil (LGPD), EUA (CCPA), Europa (GDPR)
- Terceiros: AWS (hosting), Stripe (pagamentos), Google Analytics

**Resultado:** Política completa com 14 seções, incluindo:
- Tratamento específico para cada jurisdição
- Mecanismos de consentimento granular
- Processos claros para exercício de direitos
- Informações sobre transferência internacional

## Benefícios

- **Conformidade Legal:** Atende requisitos regulatórios principais
- **Transparência:** Constrói confiança com os usuários
- **Redução de Riscos:** Mitiga penalidades e multas
- **Clareza:** Define expectativas claras sobre uso de dados
- **Escalabilidade:** Prepara para expansão internacional

## Dicas de Uso

- **Seja Específico:** Evite linguagem vaga como "melhorar o produto"
- **Atualize Regularmente:** Revise a cada mudança significativa
- **Torne Acessível:** Use linguagem simples e clara
- **Implemente Tecnicamente:** Garanta que suas práticas correspondem à política
- **Treine a Equipe:** Todos devem entender as práticas de privacidade

## ⚠️ Avisos Legais Importantes

**Este documento é apenas para fins informativos e não constitui aconselhamento legal. Sempre tenha um advogado especializado em privacidade de dados revisar a política final antes da publicação. Políticas de privacidade são documentos legalmente vinculativos que estabelecem responsabilidades da empresa; a revisão profissional é essencial.**

### Cláusulas que Requerem Revisão Legal Obrigatória:
- Base legal para processamento (GDPR)
- Mecanismos de transferência internacional
- Direitos específicos por jurisdição
- Cláusulas de retenção de dados
- Processos de resposta a requisições de titulares

## Checklist de Conformidade

### Antes de Publicar
- [ ] Advogado de privacidade revisou a política
- [ ] Práticas reais correspondem à política
- [ ] Processos implementados para atender requisições
- [ ] Medidas técnicas mencionadas estão em vigor
- [ ] DPA assinado com todos os processadores
- [ ] Base legal documentada para cada processamento

### Manutenção Contínua
- [ ] Revisar a cada 6 meses ou mudança significativa
- [ ] Monitorar novas regulamentações
- [ ] Atualizar conforme novas funcionalidades
- [ ] Manter registro de todas as atualizações
