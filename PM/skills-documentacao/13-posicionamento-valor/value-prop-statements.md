# Declarações de Proposta de Valor

## Propósito
Gerar declarações de proposta de valor a partir de propostas de valor existentes para marketing, vendas e onboarding. Cria statements que abordam segmentos alvo, enfatizam benefícios e destacam capabilities. Perfeito para crafting de conteúdo de marketing direcionado, apresentações de vendas e mensagens de onboarding de clientes.

## Como Funciona
A skill analisa propostas de valor existentes, desenvolve statements segmentados que se conectam com necessidades específicas, enfatiza benefícios primários e outcomes desejados, destaca capabilities que habilitam esses benefícios e usa linguagem clara e persuasiva para cada canal.

## Quando Usar
- Escrever copy de marketing e conteúdo promocional
- Criar sales decks e materiais de pitch
- Crafting mensagens de onboarding de clientes
- Desenvolver messaging segmentado
- Criar conteúdo para diferentes canais de distribuição

## Passo a Passo

### 1. Analisar Proposta de Valor Existente
Extrair elementos chave da proposta de valor atual:
- **Benefícios Principais:** Quais resultados o cliente obtém?
- **Capabilities Diferenciadoras:** Como esses resultados são alcançados?
- **Segmentos Alvo:** Quem se beneficia mais?
- **Problemas Resolvidos:** Quais dores são eliminadas?

### 2. Identificar Segmentos de Comunicação
Definir diferentes públicos e contextos:
- **Marketing:** Leads prospects, audiência ampla
- **Vendas:** Prospects qualificados, decisores
- **Onboarding:** Novos clientes, usuários finais
- **Sucesso:** Clientes existentes, power users
- **Parceiros:** Canal partners, integradores

### 3. Desenvolver Statements por Segmento
Criar statements específicos para cada público:

**Para cada statement:**
- **Endereçar Segmento Específico:** Fale diretamente com o público
- **Enfatizar Benefício Primário:** Outcome principal que eles querem
- **Destacar Capabilities:** Como você entrega esse benefício
- **Usar Linguagem Apropriada:** Tom e vocabulário do segmento

### 4. Adaptar para Canais Diferentes
Customizar mensagem para diferentes contextos:
- **Website Copy:** Breve, impactante, focada em ação
- **Email Marketing:** Pessoal, relevante, com call-to-action claro
- **Sales Presentation:** Detalhada, focada em ROI, com provas
- **Onboarding:** Instrutiva, encorajadora, focada em sucesso

### 5. Otimizar para Conversão
Refinar statements para máxima efetividade:
- **Clareza:** Fácil de entender e lembrar
- **Relevância:** Conecta com necessidades reais
- **Credibilidade:** Apoiada por provas e evidências
- **Urgência:** Motivação para agir agora

## Estrutura de Value Prop Statements

### Componentes Essenciais

**1. Segment Identification**
- Quem é este statement para?
- Qual é o contexto deles?
- Quais são suas prioridades?

**2. Primary Benefit**
- Qual é o resultado principal?
- Como isso melhora a vida/trabalho deles?
- Por que isso importa agora?

**3. Supporting Capabilities**
- Como especificamente você entrega isso?
- Quais features habilitam este benefício?
- Por que suas capabilities são superiores?

**4. Differentiation**
- Por que escolher você vs alternativas?
- O que torna sua abordagem única?
- Qual é sua vantagem competitiva?

## Framework de Criação

### Passo 1: Entender o Segmento
- **Quem são eles?** Cargo, indústria, tamanho da empresa
- **O que eles querem?** Objetivos, metas, aspirações
- **O que os impede?** Desafios, dores, frustrações
- **Como eles falam?** Linguagem, jargão, tom

### Passo 2: Conectar com Benefícios
- **Qual é o outcome principal?** Resultado desejado
- **Como isso melhora a vida deles?** Impacto real
- **Por que isso importa agora?** Urgência e relevância
- **Como você mede isso?** Métricas e provas

### Passo 3: Destacar Capabilities
- **Quais features entregam isso?** Funcionalidades específicas
- **Por que suas capabilities são melhores?** Diferenciação
- **Como isso funciona na prática?** Exemplos concretos
- **Quais são as provas?** Testemunhos, dados, casos

### Passo 4: Otimizar para Canal
- **Website:** SEO, clareza, call-to-action
- **Email:** Personalização, relevância, engajamento
- **Sales:** ROI, credibilidade, decisão
- **Onboarding:** Educação, sucesso, retenção

## Benefícios

- **Relevância:** Mensagens que conectam com necessidades específicas
- **Clareza:** Comunicação clara e focada em benefícios
- **Conversão:** Statements otimizados para ação
- **Consistência:** Mensagens alinhadas across canais
- **Eficiência:** Reúso de conteúdo adaptado por contexto

## Dicas de Uso

### Para Melhores Resultados:
1. **Seja Específico:** Use dados concretos e exemplos reais
2. **Fale a Linguagem Deles:** Use termos e jargões do segmento
3. **Quantifique Benefícios:** Use números e métricas sempre que possível
4. **Inclua Prova Social:** Testemunhos, casos, dados

### Erros Comuns a Evitar:
- Focar em features em vez de benefícios
- Usar linguagem genérica ou corporativa
- Ignorar contexto do canal
- Esquecer de incluir call-to-action

## Formato de Saída

**Statements Completo Incluindo:**
- Declarações por segmento e canal
- Messaging adaptado para cada contexto
- Benefícios quantificados quando possível
- Capabilities diferenciadoras destacadas
- Call-to-actions apropriados

## Framework de Validação

### Teste de Eficácia
- **Clareza:** Stakeholders entendem imediatamente?
- **Relevância:** Ressoa com público alvo?
- **Memorabilidade:** É fácil de lembrar?
- **Ação:** Motiva comportamento desejado?

### Métricas de Performance
- **Engajamento:** Click-through, tempo de leitura
- **Conversão:** Taxa de signup, demo requests
- **Qualidade:** Leads qualificados, fit de segmento
- **Retention:** Uso continuo do produto

```
[Benefício Principal] para [Segmento Alvo].

então você pode [Resultado Específico] 
sem [Problema Comum].
```
